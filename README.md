📱 สรุปฟังก์ชันและการประยุกต์ใช้เนื้อหาตาม Milestone (สัปดาห์ที่ 1–11):
1. Week 1–3 (UI & Components): ออกแบบหน้าจอ Profile นักศึกษา, สร้าง Reusable Component `EventCard`, และจัดการรายการกิจกรรมด้วย `FlatList` ที่รองรับ Responsive Spacing
2. Week 4 (Expo Router & Navigation): ออกแบบ File-based Routing ด้วย Stack และ Tabs (`/events`, `/favorites`, `/profile`) พร้อมรองรับ Dynamic Route `/events/[id]`
3. Week 5 (Forms & State Management): จัดการสถานะการบันทึกรายการโปรดด้วย React Context (`FavoritesProvider`)
4. Week 6–7 (Networking & Local Storage): จำลองการโหลดข้อมูล และทำระบบบันทึกสถานะ Favorite รวมถึง Session ลงใน Local Storage ของตัวเครื่อง
5. Week 8 (Authentication & Security): ระบบ Session Management, การเข้าสู่ระบบ (Login Flow), การออกจากระบบ (Logout) และ Protected Routes
6. Week 9–10 (Device APIs, Location & Maps): โครงสร้างรองรับสิทธิ์การเข้าถึง (Permissions), พิกัดสถานที่ และการแสดงผลแผนที่ (Interactive Map สำหรับอุปกรณ์ Mobile พร้อม Fallback สำหรับ Web)
7. Week 11 (Notifications & Platform APIs): ระบบตอบสนองการแจ้งเตือนกิจกรรมล่วงหน้า (Local Event Reminder)

🚀 ขั้นตอนการติดตั้งและรันโปรเจกต์ (สำหรับอาจารย์ตรวจงาน):
1. Clone โปรเจกต์:
   git clone [ใส่ลิงก์ GitHub ของคุณตรงนี้]
   cd campus-events
2. ติดตั้ง Dependencies:
   npm install
3. รันโปรเจกต์:
   npx expo start -c
   (สามารถเปิดทดสอบผ่านแอป Expo Go บนสมาร์ตโฟน หรือกด 'w' เพื่อเปิดบน Web Browser ได้ทันที)

โปรเจกต์ผ่านการทดสอบ Clean Install และสามารถรันได้จริงตามเกณฑ์การประเมินครับ
